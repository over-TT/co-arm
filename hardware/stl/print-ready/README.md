# Print-ready STL candidates

Place an STL here only after it is manifold, scale-checked, revision-matched,
and intentionally oriented for a documented print process. Do not add
machine-specific G-code.

For each part, record in the commit, release notes, drawing, or a future print
manifest:

- source CAD/STL revision;
- intended bed face and orientation;
- printer, nozzle, material, and material manufacturer;
- layer height, walls, top/bottom layers, infill, and supports;
- fit compensation, inserts, and post-processing;
- quantity/mirroring and the physical build used to verify fit.

All current print settings are **TODO (owner verification)**. Until those fields
are supplied, files in the parent STL folder are export candidates rather than
validated print-ready parts.
