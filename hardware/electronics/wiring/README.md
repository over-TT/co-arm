# Wiring and harness documentation

Put point-to-point harness drawings, connector tables, and carefully cropped
wiring photographs here. Schematics explain electrical intent; this folder
explains how the physical arm is actually connected.

Use names such as:

```text
co-arm_cable_servo-bus-harness_r01.pdf
co-arm_cable_camera-ribbon-routing_r01.svg
co-arm_cable_power-harness_r01.pdf
```

For every cable, document both endpoints, connector family/part number, mating
face versus wire-side view, pin numbers, wire gauge/color/length, nominal
voltage, maximum expected current, label text, strain relief, and routing near
moving joints.

Trace the harness with power disconnected and confirm conductors by continuity;
do not rely only on color. Remove private labels, serial numbers, credentials,
and unintended room details from public photographs.
