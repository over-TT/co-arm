# Media

Only reviewed, public-safe exports belong in this tracked tree.

- `photos/overview/` — complete-arm and scale views.
- `photos/assembly/` — staged construction and cable-routing views.
- `photos/details/` — labels, joints, gearing, camera, HAT, and power details.
- `diagrams/` — original SVG/PNG diagrams and captions.
- `video/` — small approved clips or link manifests.
- `raw/` — ignored intake folder for unreviewed originals; create it locally.

Follow [`docs/MEDIA_GUIDE.md`](../docs/MEDIA_GUIDE.md). Remove metadata and
review faces, screens, addresses, serials, QR codes, and unrelated desk details
before copying anything out of `raw/`.
